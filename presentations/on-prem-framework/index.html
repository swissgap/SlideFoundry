Management-Fit

Warum Reveal.js für anspruchsvolle Decks trägt

Stark für Präsentierende

  • Speaker Notes, Foliennummern und Keyboard-Steuerung
  • Saubere PDF-Ausgabe über den Browser-Druckdialog
  • Gut versionierbar in Git

Stark für Organisationen

  • Branding zentral über CSS steuerbar
  • Deployment auf Fileserver, Intranet oder lokalem Notebook
  • Keine Datenübertragung an externe Präsentationsdienste
Entscheidung

Pragmatische Leitlinie

Reveal.js, wenn das Ergebnis hochwertig, interaktiv und markenkonform sein soll.

Marp, wenn Geschwindigkeit und Markdown-Export im Vordergrund stehen.

Quarto, wenn Daten, Code und reproduzierbare Reports Teil des Decks sind.

Für den beschriebenen On-Premise-Einsatz: Reveal.js als Standard, Marp und Quarto als spezialisierte Werkzeuge daneben.
